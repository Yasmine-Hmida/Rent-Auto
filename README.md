# Rent-Auto

## Overview

**Rent-Auto** is a MERN stack web-based platform for managing fleet rentals, clients and all aspects of the contracts designed for tunisian fleet agencies. 

## Technologies Used

- ReactJS (For the Frontend).
- NodeJS, ExpressJS (For the Backend).
- MongoDB (For the Database).
- Socket.IO (For emitting real-time events in the platform).
